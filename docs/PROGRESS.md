## API 계약 변경 (be/core → main 병합으로 `docs/API.md`에 반영 완료)
- 시청 identity `member-{id}-{8자리}` / `guest-{uuid}` (같은 사람이 탭 두 개 열어도 끊기지 않게). 채팅 이름은 participant `name` 사용
- `/viewer-token`: LIVE 아니면 409 `BROADCAST_NOT_LIVE`, LiveKit 키 없으면 503 `LIVEKIT_NOT_CONFIGURED`
- 401은 `UNAUTHORIZED`(토큰 없음)와 `INVALID_TOKEN`(만료·위조) 두 종류
- `/start`: LIVE 중 재호출은 토큰만 재발급, ENDED도 다시 시작 가능 (FE가 `66f25a6`에서 '다시 방송' 버튼으로 맞춤 → 해결)
- 데모 계정: `streamer@demo.test` / `viewer@demo.test` (BE·FE 동일)
